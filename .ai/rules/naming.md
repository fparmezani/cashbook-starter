# Rule: naming

- Projetos: `CashBook.<Area>.<Camada>` (ex.: `CashBook.Ledger.Domain`).
- Entidades e use cases em PascalCase. Arquivos C# com o nome da classe.
- Erros: `Entidade.Codigo` (`Account.NameRequired`).
- Endpoints: `/api/<recurso>` no plural.
- Features Angular em kebab-case no path (`accounts`, `categories`, `transactions`, `reports`).
- Nunca abreviar (`AccountRepository`, nunca `AccountRepo`).
