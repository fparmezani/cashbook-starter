# Workflow: implementar uma spec

Use uma sessão nova por spec.

1. Ler a spec inteira. Não começar pelo código.
2. Listar as skills e rules citadas. Carregar só essas.
3. Executar as tarefas na ordem. Uma fase por vez.
4. Depois de cada fase: o comando de validação da fase.
5. Registrar evidência na spec (data, comando, resultado).
6. Se falhar: corrigir. Se falhar de novo na aula: checkout da tag do encontro (plano B).
7. Não encadear a spec seguinte na mesma conversa.
